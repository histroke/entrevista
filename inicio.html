part 3 — portfolio project

SafeStart: a teen pregnancy prevention platform

social impact backend / API

1. What is it?

SafeStart is a web platform I built to support a local teen pregnancy prevention program. I was responsible for the backend: the API, the database, and the logic that connects everything.

2. What was the purpose?

The purpose was to give teenagers a private, reliable way to access sexual health information, book confidential appointments with a counselor, and ask anonymous questions without fear of judgment.

3. What did you do?

  • Designed the database in MongoDB to store users, appointments, and anonymous questions
  • Built REST API endpoints for registration, login, and appointment scheduling
  • Created an anonymous Q&A endpoint that never stores identifying information
  • Implemented data validation and basic security rules

4. What tools did you use?

I used JavaScript with Node.js for the server logic, MongoDB for the database, and Git for version control. The frontend team used the API I built to display the content.

5. What was challenging?

The main challenge was protecting user privacy while still allowing appointment tracking. I solved this by separating identity data from the anonymous question data, so no question could ever be linked back to a specific user.

6. Why is it relevant?

This project shows that I can build a secure, responsible backend system for sensitive real-world data, which is exactly the kind of judgment a backend developer needs.

Sample interview answers

I would say my strongest skill is logical problem-solving. I use it every day when I design database structures or debug an API.

Q: Can you tell me about one of your projects?

Sure. I built the backend for SafeStart, a platform that supports a teen pregnancy prevention program. I designed the database and built the API that handles appointments and anonymous questions.

Q: What was the most difficult part?

The main challenge was protecting user privacy. I solved this by keeping identity data completely separate from the anonymous questions in the database.

I enjoy working in a team, because I can focus on the backend while others handle the design, and we combine our skills to build something better together.
